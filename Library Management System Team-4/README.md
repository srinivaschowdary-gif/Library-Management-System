# Library Management System

## Project Overview
The Library Management System is a web-based application developed to manage library operations digitally.  
It helps in maintaining book records, user details, and book issue/return activities efficiently.

This project is developed as a team project using modern web and backend technologies.

---

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Java
- Spring Boot
- REST APIs

### Database
- MongoDB

### Version Control
- Git
- GitHub

---

##  System Architecture

Frontend (HTML, CSS, JavaScript)  
⬇  
Backend (Spring Boot REST APIs)  
⬇  
Database (MongoDB)

The frontend communicates with the backend using RESTful APIs, and the backend performs CRUD operations on MongoDB.

---

##  Project Modules

### 1. User Module
- User registration
- User login
- View user details

### 2. Book Module
- Add new books
- Update book details
- Delete books
- View available books
- Search books

### 3. Issue & Return Module
- Issue books to users
- Return books
- Track issued and returned books

### 4. Admin Module
- Manage users
- Manage books
- Monitor transactions

---

## Database Design

### Collections:
- Users
- Books
- Transactions

Each collection stores data in JSON document format.
